### Was wird getauscht?

| Bauteil | Empfehlung |
|---|---|

| Spannrolle | ✅ Immer mit tauschen |
| Umlenkrolle | ✅ Immer mit tauschen |

### A14NET Motor – Besonderheiten

- **Interne Steuerkette / Zahnriemen**: Der A14NET hat einen **Zahnriemen** (keine Steuerkette!)
- Bei Riss des Zahnriemens: **Motorschaden** (Ventile treffen Kolben – "interferenzmotor")
- **Kein Overrun / Freilauf** – Zahnriemenbruch = Totalverlust
- Nach Zahnriemenwechsel: Zündeinweisung prüfen lassen

## 5. Wartungsleuchte / Service-Indicator Resetten

### Methode 1: Über Bordcomputer (bei manchen Modellen)

1. Zündung ausmachen
2. Taster für "Reset" (Trip-Odometer) gedrückt halten
3. Zündung einschalten
4. Warten bis "InSP" oder Service-Interval im Display erscheint
5. Taster 10 Sekunden gedrückt halten
6. Display flackert → Reset erfolgt

### Methode 2: Über OBD-II Diagnosetool

1. OBD-II Scanner anschließen (unter Lenkrad)
2. "Service Reset" oder "Oil Life Reset" auswählen
3. Je nach Tool: "Reset Service" bestätigen
4. Service-Counter wird auf 100% zurückgesetzt

### Methode 3: Über Diagnosetool (Tech2 / OP-COM / GDS2)

1. Diagnosetool mit Fahrzeug verbinden
2. Steuergerät "BCM" oder "Kombiinstrument" auswählen
3. "Service-Reset" durchführen
4. Bestätigen

### Wichtig
- Service-Reset **nach** dem Ölwechsel durchführen
- Bei nächster Diagnose werden noch alte Service-Daten angezeigt
- **OP-COM** oder **Tech2** sind die zuverlässigsten Tools für Opel

### Typische Kosten

| Posten | Preis |
|---|---|
| OBD-II Bluetooth-Adapter | 20–50 € |
| OP-COM Kabel | 30–100 € |
| Service-Reset in Werkstatt | 10–30 € (oft inklusive) |
| Tech2 Mietgerät | 50–100 € / Tag |

## 7. P0300–P0304: Zündaussetzer (Misfire) – Detaillierte Analyse

### Bedeutung

| Code | Bedeutung |
|---|---|
| **P0300** | Zufällige/mehrere Fehlzündungen in verschiedenen Zylindern |
| **P0301** | Fehlzündung in Zylinder 1 |
| **P0302** | Fehlzündung in Zylinder 2 |
| **P0303** | Fehlzündung in Zylinder 3 |
| **P0304** | Fehlzündung in Zylinder 4 |

### Häufige Ursachen beim Astra J 1.4 Turbo

| Ursache | Wahrscheinlichkeit | Kosten |
|---|---|---|
| **Zündkerzen verschlissen** | ⭐⭐⭐⭐⭐ | 30–60 € (Set) |
| **Zündspulen defekt** | ⭐⭐⭐⭐ | 20–50 € / Stück |
| **Kraftstoffdruck zu niedrig** | ⭐⭐⭐ | 100–300 € |
| **Injektoren verschmutzt** | ⭐⭐⭐ | 50–150 € (Reinigung) |
| **Kompressionsdruck zu niedrig** | ⭐⭐ | 300–800 € (Ventilspiel/Kopfdichtung) |
| **Ventilspiel zu groß** | ⭐⭐ | 200–400 € |
| **PCV-Ventil defekt (Ventildeckel)** | ⭐⭐⭐⭐ | 50–150 € |
| **Ladedruck undicht** | ⭐⭐⭐ | 100–500 € |

### Symptome
- Motor ruckelt / läuft unruhig
- Leistungsverlust
- Höherer Kraftstoffverbrauch
- Motorkontrollleuchte blinkt (bei aktiver Fehlzündung)
- Auspuffgeruch nach unverbranntem Kraftstoff

### Diagnoseschritte

1. **OBD-II auslesen** – Alle Codes notieren (nicht nur P0300!)
2. **Zündkerzen prüfen** – Zustand und Elektrodenabstand
3. **Zündspulen prüfen** – Tauschen zwischen Zylindern
4. **Kompression prüfen** – Mindestens 11 bar, Differenz max. 1 bar
5. **Kraftstoffdruck prüfen** – Muss 3,5–4,5 bar betragen
6. **Leckluft prüfen** – Besonders beim Ladedrucksystem

## 8. P0171/P0174: Kraftstoffgemisch zu mager

### Bedeutung

| Code | Bedeutung |
|---|---|
| **P0171** | Kraftstoff-Luft-Gemisch Bank 1 zu mager |
| **P0174** | Kraftstoff-Luft-Gemisch Bank 2 zu mager (nur bei 6-Zyl.) |

**Hinweis:** Beim 4-Zylinder Astra J kommt fast immer nur **P0171** vor.

### Häufige Ursachen beim Astra J 1.4 Turbo

| Ursache | Wahrscheinlichkeit | Kosten |
|---|---|---|
| **Ansaugleckage (Leckluft)** | ⭐⭐⭐⭐⭐ | 10–100 € (Schlauch/Membran) |
| **MAF-Sensor verschmutzt** | ⭐⭐⭐⭐ | 20–50 € (Reinigung) |
| **PCV-Ventil / Membran im Ventildeckel** | ⭐⭐⭐⭐⭐ | 50–150 € (Ventildeckel) |
| **Kraftstoffdruck zu niedrig** | ⭐⭐⭐ | 100–300 € (Pumpe) |
| **Luftmassenmesser (MAF) defekt** | ⭐⭐⭐ | 80–200 € |
| **Lambdasonde (O2) vor Katalysator** | ⭐⭐ | 80–200 € |
| **Tankentlüftungsventil (AKF-Ventil)** | ⭐⭐⭐ | 20–60 € |
| **Injektoren undicht** | ⭐⭐ | 100–300 € |

### PCV-Ventil – Häufigstes Problem beim A14NET!

Das **PCV-Ventil (Crankcase Ventilation)** ist im **Ventildeckel** integriert. Bei undichter Membran tritt Ölverlust / Druckverlust auf und es kommt zu P0171 + P0299 gleichzeitig!

**Tausche den Ventildeckel komplett** (Membran kann nicht einzeln getauscht werden).

### Diagnoseschritte

1. **OBD-II Live-Daten prüfen**: Kurzzeit-Lambdasteuerung muss zwischen +10% und -10% schwingen
2. **Leckluftprüfung**: Mit Rauchmaschine oder Seifenwasser an Ansaugschläuchen
3. **MAF-Sensor prüfen**: Messwerte mit Sollwerten vergleichen
4. **Kraftstoffdruck messen**: Muss im Leerlauf mindestens 3,5 bar betragen
5. **PCV-Membran prüfen**: Ölverlust am Ventildeckel erkennen

## 15. Checkliste: Wann zum Meister?

| Symptom | Dringlichkeit | Maßnahme |
|---|---|---|
| MKL leuchtet (dauerhaft) | 🟡 Mittel | Auslesen lassen, aber fahrbereit |
| MKL blinkt | 🔴 Hoch | SOFORT Werkstatt! Fehlzündung aktiv |
| Leistungsverlust | 🟡 Mittel | OBD auslesen |
| Ruckeln / Stocken | 🟡 Mittel | Zündkerzen + Lambdasonde prüfen |
| Ölverbrauch >0,5L/1000km | 🟡 Mittel | Turbolader + Dichtungen prüfen |
| Rauch aus Auspuff (blau) | 🔴 Hoch | Turbolader / Ölverbrauch |
| Rauch aus Auspuff (weiß) | 🟡 Mittel | Kopfdichtung / Kühlmittel |
| GetriebeQuietschen | 🟡 Mittel | Getriebeöl-Wechsel |
| Zahnriemen >120.000km | 🔴 Hoch | SOFORT wechseln! |
